# Факты и формулировки — PCB Восток

Единый источник цифр, терминов и формулировок для всех чатов проекта. Тексты сайта не должны противоречить этому файлу. Здесь — только пункты с решённым статусом и открытые противоречия; вопросы, ответы коллег и сверки ведутся в рабочем файле (Excel).

**Статусы:**
- ✅ **Подтверждено** — можно использовать в текстах.
- 🔒 **Не публикуем** — внутренняя информация: учитываем при написании, но на сайте не упоминаем.
- ⛔ **Не использовать** — отвергнуто или неверно.

**Источники:** «сайт» — актуальное превью главной и `20-homepage.html` в ветке `ivan_claude`; «Kimi» — старый референс `Kimi_refference.html`; «чат» — решение рабочего чата проекта; «пользователь» — решение заказчика сайта; «коллега» — описание этапов от сотрудника компании (сентябрь 2026); «коллега (Q-n)» — его ответ на вопрос Q-n рабочего файла.

**ID:** `F-<раздел>.<номер>` — факты, `T-<n>` — термины, `R-<n>` — отвергнутые формулировки, `C-<n>` — противоречия, `P-<n>` — правила подачи, `S-<n>` — разграничение секций. ID постоянные: новые пункты получают следующий свободный номер в разделе, удалённые номера не переиспользуются. Правки из разных чатов привязываются к ID. Закрытые противоречия из файла убираются, их история — в рабочем файле.
