      Какие файлы подойдут

      Файл IPC-2581 (.xml или .cvg) — лучший вариант. Один файл заполнит параметры платы и монтажа: габариты, слои, толщину, медь, материал, отверстия, число и типы компонентов, стороны монтажа. Покрытие и цвет маски — если они указаны в проекте.

      ZIP-архив с Gerber и сверловкой — габариты, число слоёв, отверстия, минимальная ширина дорожки и число SMD-площадок для грубой оценки монтажа.

      Файл .gbrjob — толщина платы, медь, материал, финишное покрытие, цвет маски и маркировки.

      Файлы можно добавлять по одному или вместе. Если данные в них расходятся, мы отметим это у поля. RAR и 7z калькулятор не читает — перепакуйте проект в ZIP или приложите архив к заявке.

      Как выгрузить из САПР

      Есть два способа:

      1. IPC-2581 — один файл, из которого заполняется больше всего полей.
      2. ZIP с Gerber и сверловкой, а если САПР умеет — ещё и .gbrjob.
      KiCad 8 и новее Beta

      IPC-2581: «Файл → Выходные файлы для производства → IPC-2581» (File → Fabrication Outputs → IPC-2581).

      Gerber и .gbrjob: «Файл → Графический вывод», отметьте «Создать файл задания Gerber», нажмите «Вывести», затем «Создать файлы сверловки». Упакуйте всё в один ZIP.

      Чтобы в файлах были толщина и покрытие, заполните «Параметры платы → Стек слоёв».

      Altium Designer Beta

      IPC-2581: File » Fabrication Outputs » IPC-2581. Файл сохранится с расширением .cvg — загружайте его как есть.

      Gerber: File » Fabrication Outputs » Gerber X2 Files и NC Drill Files, затем упакуйте в один ZIP. Файл .gbrjob Altium не создаёт.

      OrCAD / Allegro Beta

      IPC-2581: File → Export → IPC 2581.

      Gerber: Export → Gerber (окно Artwork Control Form) и отдельно NC Drill, затем упакуйте в один ZIP.

      EasyEDA Pro Beta

      Gerber: «Экспорт → Файл изготовления PCB (Gerber)» — получится готовый ZIP с Gerber и сверловкой.

      Толщину, медь и покрытие укажите в полях ниже вручную.

      Другие САПР: ZIP с Gerber (лучше в формате X2) и сверловкой, остальные параметры — вручную.

      Beta Пути в меню уточняем — в вашей версии САПР они могут отличаться.

      Куда попадают файлы

      Никуда. Файлы разбираются прямо в вашем браузере и не отправляются на сервер. К нам они попадут, только если вы сами приложите их к заявке.

      Не хотите загружать? Откройте файлы в бесплатной программе с открытым кодом — KiCad GerbView или gerbv — и перенесите значения в поля вручную.

      Отправка на точный расчёт

      В калькуляторе — ориентировочная цена. Приложите данные расчёта и файлы проекта: точную стоимость назовём после их разбора.

      [pcb_request_form context="calc"]

      Ориентировочная стоимость партии

      —

        Как считается

        Плата: подготовка производства + площадь партии в дм² × ставка за число слоёв × коэффициенты (толщина, медь, покрытие, маска) × скидка за объём.

        Монтаж: подготовка (трафарет, программа, первый образец) на каждую сторону + заправка питателей + паяные соединения × ставка по группе корпусов + выводы DIP. Число заправляемых питателей оцениваем по количеству компонентов.

        Показываем диапазон: точная цена — после аудита файлов.

        Ставки демонстрационные — формулу соберём отдельно.

        Оценка не является офертой. Окончательную цену определяем после аудита файлов.
